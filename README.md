# IsaBot

> **This repository is no longer developed.** On 2026-09-22 the bot was split into two separate projects, each with its own repository:
>
> * **[barnabus-bot](https://github.com/Raw-Darkness/barnabus-bot)** — moderation and community features: mod log, user records, safety monitor, spam/flood detection, honeypot, XP ranks, highlights, stats channels, FAQ answers, `/wiki`, `/lore`, Translate and the daily digest. No chat persona, no image generation.
> * **[isabell-bot](https://github.com/Raw-Darkness/isabell-bot)** — roleplay chat and image generation only, with layered safety controls: word filters, a model second opinion, a vision review of every rendered image, age-restricted channel gating and a cooldown for repeat offenders.
>
> Splitting them means the moderation bot keeps running when the image bot is down, the image bot holds no moderation permissions, and each half can be hosted where it fits best. The code below is kept for reference only; bug fixes and new features go to the two repositories above.

---

A python Discord bot with an LLM persona. It chats like a regular user (no commands needed), generates images through a local Stable Diffusion instance, and helps moderate the server. Point it at any OpenAI-compatible API (OpenAI, OpenRouter, or a locally hosted model).

#### Disclaimer:
The code of this bot has mostly been generated by AI and I am by no means a good coder. It works but thats about it :)

### Features
* **Persona chat** — replies in character in allowed channels and in DMs. Configurable personality and optional world lore file injected into the system prompt.
* **Persistent memory** — per-channel and per-DM conversation history that survives restarts. When the history window fills up, the oldest half is compressed into an LLM-written summary so context is kept without blowing the token budget.
* **Image generation** — trigger words like "draw …" send a prompt through an LLM prompt-engineering pass and then to the Automatic1111 API (prompts that are already comma-separated tag lists skip the rewrite, and `draw exact:` forces that). Every image carries **buttons**: 🔁 Redo · ✨ Variation · ⬆️ Upscale (hires fix) · 📋 Prompt (shows prompt + seed privately). Change requests ("make it darker", or replying to any of the bot's images) keep the **seed** and run **img2img** on the previous output so the composition stays put; a bare "again" rerolls with a fresh seed. Extras: live progress % while rendering, "portrait"/"landscape" hints pick preset sizes, "3x" renders a batch, `style:<name>` applies a configured style preset, generations queue with position feedback, and the bot says so when the backend is offline. Rate-limited per user; image history persists across restarts.
* **Moderation**
  * Mod log: deleted messages (with content when cached), edit before/after, bulk purges, and bans/unbans posted as embeds to a private log channel.
  * User records: spam flags, flood detections, and honeypot trips are automatically written to a per-user SQLite record; mods can add manual notes with `!note` and look anyone up with `!record` (also summarized in `!whois`). Rejoining does not clear a record — Discord user IDs are permanent.
  * Honeypot channel: anyone posting in it is removed and their recent messages are wiped **server-side** via a ban with `delete_message_seconds` (by default immediately unbanned again — a "softban" with kick semantics), then mods get notified. Admins and configured roles are exempt. This needs the **Ban Members** permission; without it the bot falls back to kick + a manual two-pass purge, which can miss very recent messages.
  * Spam detection: Discord invite links and scam URL patterns from new accounts are flagged to the mod channel.
  * Flood detection: identical messages posted across multiple channels are flagged.
* **Mod commands** (in DMs or the mod channel, for the owner and users with the mod role):
  * `!summary [Nh]` — LLM-written digest of server activity
  * `!activity` — most active channels (last 6h)
  * `!whois <user>` — member lookup (use a user ID; lookup by name needs the privileged members intent which is off by default)
  * `!flags` — recent spam/flood alerts
  * `!search <term>` — search recent messages
  * `!clearhistory [channel_id]` — wipe the bot's memory for a channel
  * `!note <user> <text>` / `!record <user>` — mod notes and per-user incident history
  * `!reload` (owner) — reload config from disk
  * `!help` — list available commands
* **FAQ auto-answer** — point the bot at a questions forum channel and a plain-text FAQ file: when a question thread has sat without any human reply for a configurable delay (default 30 min), the bot answers it — grounded strictly in the FAQ file, staying silent when the FAQ doesn't cover the question. Community-first by design: humans always get the first shot. Anyone can also use the **`/ask`** slash command for an instant private (ephemeral) answer from the same FAQ.
* **`/wiki <term>`** — searches a MediaWiki-based game wiki and returns the best page with a snippet and further results (private by default, `share: true` posts it publicly). No LLM involved.
* **`/lore <topic>`** — in-character answer grounded strictly in the full lore file, shown only to the asker. In ordinary chat the bot carries a compact lore summary instead, and pulls in the relevant full-lore section only when a message actually names an NPC, faction or place — keeping prompts small without losing depth.
* **Image safety** — image generation has a master switch (`ImageGenerationEnabled`) and a hard refusal filter for prompts seeking sexualised minors. The filter runs on both the raw user text and the final prompt sent to Stable Diffusion (the LLM rewrite step sits between them, so checking only one would be a bypass), normalises leetspeak and spaced-out spellings, and catches stated ages under 18. Its built-in term list **cannot be disabled or removed via config** — `ImageBlockExtraTerms` can only add to it. Refusals are logged, written to the user's moderation record, and alerted to the mod channel.
* **Chat safety** — the same protection on the text side, which needs to be more careful than the image filter because roleplay about offspring is legitimate. Terms with no innocent use are refused outright; words describing a minor as a person, or a stated age under 18, are refused when the message is sexual; and ambiguous words like "child" only trigger when a hard sexual term sits within a few words. Age context is carried across recent turns, so establishing a minor in one message and turning sexual in the next is still caught. The bot's **own replies** are checked too, and a blocked exchange is dropped from conversation memory so it cannot seed later turns.
* **Model-decided drawing** (`ImageToolEnabled`) — besides keyword triggers, the chat model is offered a `generate_image` tool and calls it when the user is actually asking to be shown something, in any language. It writes the Stable Diffusion prompt itself from the conversation, so no separate prompt-compose call is needed. Requires a model that supports tool calling.
* **`/draw`** — the image pipeline as a slash command with style preset autocomplete, aspect choice, batch count, and an exact-prompt switch.
* **Highlights** — messages that collect enough ⭐/❤️ reactions (configurable set, unique voters) are reposted to a highlights channel; by default only the bot's own generated images qualify (credited to the requester with their prompt), configurable to any message.
* **Server stats channels** — periodically renames channels to show the member count and, via Steam's public API, how many players are in the game right now.
* **Translate** — right-click any message → Apps → **Translate**: the bot translates it into the reader's own Discord language (auto-detected from their client locale) and shows it only to them. No flags to learn, no channel clutter.
* **Leveling** — MEE6-style XP: 15-25 XP per message with a per-user cooldown so chatting earns and spamming doesn't, with configurable level-up announcements ({name}/{level} templates), optional role rewards at level thresholds, and excluded channels. Public commands for everyone: `!rank` (or `!level`), `!top` (or `!leaderboard`).
* **Daily digest** — optional scheduled server summary DM'd to the owner.
* **Hot-reloadable config** — the config file is watched and reloaded on change.

### Setup
1. Create a Discord application and bot, and enable the **Message Content** privileged intent in the developer portal. See https://discord.com/developers/docs/quick-start/getting-started or the step-by-step guide at https://www.wikihow.com/Create-a-Bot-in-Discord
2. `pip install -r requirements.txt` (Python 3.10+)
3. Copy `Config.example.json` to `Config.json` and fill in your Discord token, API key, endpoint, and channel/role IDs. Enable Developer Mode in Discord to copy IDs — see https://support.discord.com/hc/en-us/articles/206346498-Where-can-I-find-my-User-Server-Message-ID- for how to find them. `Config.json` is gitignored so your secrets stay out of the repo. <img width="1004" alt="config file example" src="https://github.com/Raw-Darkness/IsaBot/assets/154023932/5f7f4f2a-cf66-429a-80e0-6581a8b90071">
4. Run it: `python3 IsabellBot.py` <img width="305" alt="bot running in console" src="https://github.com/Raw-Darkness/IsaBot/assets/154023932/20a92be5-1f46-4553-8bb7-4b78b34a4e19">

For image generation, run [Automatic1111 WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui) with `--api` and point `SDURL` at it. If the SD endpoint is unreachable the bot degrades gracefully and just tells the user it couldn't render.

To run it as a service on Linux (or WSL2 with systemd enabled), something like:

    [Unit]
    Description=IsaBot
    After=network.target

    [Service]
    User=youruser
    WorkingDirectory=/path/to/IsaBot
    ExecStart=/usr/bin/python3 /path/to/IsaBot/IsabellBot.py
    Restart=always
    RestartSec=5

    [Install]
    WantedBy=multi-user.target

### Config reference

    "DiscordToken":          your bot token
    "OpenAPIKey":            API key for your LLM provider (OpenAI, OpenRouter, or local)
    "OpenAPIEndpoint":       base URL of the OpenAI-compatible API
    "OpenaiModel":           model name at that endpoint

    "Name":                  the bot's name (also used for name-mention detection)
    "Personality":           system-prompt personality. Keep it tight — it is sent with every message
    "LorePath":              optional plain-text file with world/lore knowledge (used in full by /lore)
    "LoreChatPath":          compact lore injected into every chat message (empty = use the full file). A large lore file sent on every turn dominates API cost; keep this one short. Both files hot-reload when edited.
    "LoreRetrievalEnabled":  when a message names something from the world (an NPC, faction or place), append the matching section of the FULL lore just for that message
    "LoreRetrievalMaxChunks" / "LoreRetrievalMaxTokens": how much retrieved lore may be added per message

    "AllowedChannels":       channel IDs the bot chats in (DMs always work)
    "IgnoredUsers":          user IDs to ignore (e.g. other bots)
    "IgnoredWords":          messages containing these words are ignored
    "OnlyWhenCalled":        if true, only reply in channels when mentioned or named

    "SDURL":                 Automatic1111 txt2img API endpoint
    "SDPositivePrompt":      tags prepended to every image prompt
    "SDNegativePrompt":      negative prompt for every generation
    "SDSteps" / "SDHeight" / "SDWidth" / "cfg_scale" / "SDSampler" / "scheduler": generation settings
    "ImagePromptMaxChars":   max length of the LLM-composed SD prompt
    "SDTimeout":             generation HTTP timeout in seconds
    "SDMaxConcurrent":       parallel generations (keep 1 for a single GPU)
    "SDOfflineNotice":       message shown when the SD backend is unreachable
    "SDMaxBatch":            max images per request via "Nx"
    "SDVariationStrength":   subseed strength for the Variation button
    "SDUpscaleFactor" / "SDHiresUpscaler": hires-fix settings for the Upscale button
    "SDImg2ImgDenoise":      denoising strength for img2img refinements
    "SkipRewriteForTagPrompts": skip the LLM rewrite for comma-heavy tag prompts
    "ImageToolEnabled":      let the chat model decide when to draw via a generate_image tool (needs tool-calling support)
    "LLMEnabled":            master switch for every language-model call. false = moderation-only mode: mod log, records,
                             spam/flood detection, XP ranks, /wiki, highlights and stats keep working; chat replies, /ask,
                             /lore, Translate, FAQ auto-answers, digests and image prompts are all off
    "LLMDisabledNotice":     reply when someone DMs or @mentions the bot while LLMEnabled is false
    "ImageGenerationEnabled": master switch for all image generation (false disables every drawing path)
    "ImageDisabledNotice":   message shown when image generation is switched off
    "ImageRefusalMessage":   message shown when a prompt is refused by the safety filter
    "ImageBlockExtraTerms":  additional blocked terms (adds to the built-in list; cannot remove from it)
    "ImageBlockAgeUnder":    stated ages below this are refused (default 18)
    "ImageBlockAlertMods":   send refused prompts to the mod channel
    "ChatFilterEnabled":     refuse chat messages (and bot replies) that sexualise minors
    "ChatRefusalMessage":    message shown for a hard match (a term with no innocent use)
    "ChatRefusalMessageSoft": message shown for a contextual match, which can be a misunderstanding — keep it non-accusatory. No automated punishment is ever applied; alerts go to moderators for a human decision
    "ChatBlockExtraTerms":   additional always-blocked chat terms (adds to the built-in list)
    "ChatOffspringProximity": how close a hard sexual term must be to "child"/"baby" to trigger (default 3 words)
    "ChatBlockAlertMods":    send refused chat to the mod channel
    "ImageFollowupWindowSec": how long follow-ups stay attached to the last image
    "SDPortraitSize" / "SDLandscapeSize": [width, height] when the prompt says portrait/landscape
    "SDStylePresets":        {"name": {"positive": "...", "negative": "..."}} applied via style:<name>
    "ImageMemoryPath":       where image history (prompts/seeds) is stored

    "SummaryOwnerID":        your Discord user ID — enables owner commands and receives daily digests (0 = disabled)
    "DailySummaryEnabled":   send a daily server digest to the owner
    "SummaryHour" / "SummaryTimezone" / "SummaryMaxPerChannel": digest scheduling

    "ModChannelID":          channel where mod alerts are posted and mod commands work (0 = disabled)
    "ModLogChannelID":       private channel for the mod log — deletes, edits, bans, joins/leaves (0 = disabled)
    "DatabasePath":          SQLite file for per-user records
    "EnableMembersIntent":   set true AFTER enabling Server Members Intent in the developer portal (reserved for member-based features)
    "XPEnabled":             turn the leveling system on/off
    "XPPerMessageMin" / "XPPerMessageMax" / "XPCooldownSec": XP per counted message and per-user cooldown
    "XPExcludedChannels":    channel IDs that never award XP (bot/spam channels)
    "XPAnnounceChannelID":   where level-ups are announced (0 = same channel as the message)
    "XPAnnounceRanksOnly":   if true, only rank-threshold level-ups are announced; in-between levels are silent
    "XPRoleRewards":         {"level": role_id} rank roles; promotion swaps the lower rank for the higher one
    "XPTierMessages":        {"level": "..."} special announcements when a rank is reached ({name}/{level})
    "XPStarLevel" / "XPStarPortraitPrompt": top-tier ceremony — reaching this level also generates a commemorative image
    "LevelUpMessages":       level-up templates with {name} and {level} placeholders

    "FAQEnabled":            turn the questions-forum auto-answer on/off
    "FAQPath":               plain-text FAQ file that grounds the answers
    "QuestionsForumID":      the forum channel to watch (0 = disabled)
    "FAQAnswerDelayMin":     minutes a thread must sit unanswered before the bot replies
    "FAQMaxThreadAgeHours":  never answer threads older than this
    "FAQMaxAnswersPerScan":  cap per 10-minute scan (avoids bursts after downtime)
    "FAQRetrievalMinTokens": once the FAQ file grows past this, only the best-matching entries are sent instead of the whole file
    "FAQRetrievalMaxTokens": budget for those selected entries
    "UtilityModel":          cheaper model for mechanical tasks — memory summaries, image-prompt rewriting, FAQ, translation (empty = main model). Pick one that does not refuse your server's content; the main model stays for persona chat
    "FAQModel" / "TranslateModel" / "LoreModel": optional per-task overrides of UtilityModel
    "WikiBaseURL":           base URL of a MediaWiki wiki for /wiki (empty = disabled)
    "HighlightsChannelID":   channel for starred highlights (0 = disabled)
    "HighlightEmojis" / "HighlightThreshold": accepted reactions (any of them count) and the number of unique voters needed. Custom server emoji are listed by name (e.g. "MyHeart"). The bot needs Send Messages, Embed Links and Attach Files in the highlights channel
    "HighlightImagesOnly":   true = only the bot's own images qualify; false = any message
    "StatsEnabled":          turn the stats channel renaming on (bot needs Manage Channels on those channels)
    "StatsMemberChannelID" / "StatsMemberTemplate": channel renamed to the member count, e.g. "all-members-{count}"
    "StatsPlayersChannelID" / "StatsPlayersTemplate" / "SteamAppID": channel renamed to current Steam players
    "StatsUpdateMin":        minutes between updates (minimum 10 — Discord rate-limits channel renames)
    "AppCommandGuildID":     guild to register slash commands in (instant); 0 = global (up to an hour to appear)
    "ModRoleID":             role allowed to use mod commands (0 = disabled)
    "HoneypotChannelID":     posting here gets non-exempt users removed (0 = disabled)
    "HoneypotExemptRoleIDs": roles exempt from the honeypot
    "HoneypotAction":        "kick" (softban: ban to wipe messages, then instantly unban) or "ban" (permanent)
    "HoneypotDeleteSeconds": how far back Discord wipes the offender's messages (default 600 = 10 min, max 604800)
    "HoneypotNotifyChannelID": where honeypot removals are announced (0 = the mod log channel, or the mod channel if no log)

    "ChannelHistoryPath":    where channel conversation memory is stored
    "DMHistoryDir":          directory for per-user DM memory
