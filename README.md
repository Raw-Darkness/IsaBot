# IsaBot
A python Discord bot with an LLM persona. It chats like a regular user (no commands needed), generates images through a local Stable Diffusion instance, and helps moderate the server. Point it at any OpenAI-compatible API (OpenAI, OpenRouter, or a locally hosted model).

#### Disclaimer:
The code of this bot has mostly been generated by AI and I am by no means a good coder. It works but thats about it :)

### Features
* **Persona chat** — replies in character in allowed channels and in DMs. Configurable personality and optional world lore file injected into the system prompt.
* **Persistent memory** — per-channel and per-DM conversation history that survives restarts. When the history window fills up, the oldest half is compressed into an LLM-written summary so context is kept without blowing the token budget.
* **Image generation** — trigger words like "draw …" send a prompt through an LLM prompt-engineering pass and then to the Automatic1111 API. Follow-up messages ("make it darker", "again", or replying to the image) refine the previous prompt. `draw exact:` skips the prompt rewrite. Rate-limited per channel and per user.
* **Moderation**
  * Honeypot channel: anyone posting in it is removed and their recent messages are wiped **server-side** via a ban with `delete_message_seconds` (by default immediately unbanned again — a "softban" with kick semantics), then mods get notified. Admins and configured roles are exempt. This needs the **Ban Members** permission; without it the bot falls back to kick + a manual two-pass purge, which can miss very recent messages.
  * Spam detection: Discord invite links and scam URL patterns from new accounts are flagged to the mod channel.
  * Flood detection: identical messages posted across multiple channels are flagged.
* **Mod commands** (in DMs or the mod channel, for the owner and users with the mod role):
  * `!summary [Nh]` — LLM-written digest of server activity
  * `!activity` — most active channels (last 6h)
  * `!whois <user>` — member lookup (use a user ID; lookup by name needs the privileged members intent which is off by default)
  * `!flags` — recent spam/flood alerts
  * `!search <term>` — search recent messages
  * `!clearhistory [channel_id]` — wipe the bot's memory for a channel
  * `!reload` (owner) — reload config from disk
  * `!help` — list available commands
* **Daily digest** — optional scheduled server summary DM'd to the owner.
* **Hot-reloadable config** — the config file is watched and reloaded on change.

### Setup
1. Create a Discord application and bot, and enable the **Message Content** privileged intent in the developer portal. See https://discord.com/developers/docs/quick-start/getting-started or the step-by-step guide at https://www.wikihow.com/Create-a-Bot-in-Discord
2. `pip install -r requirements.txt` (Python 3.10+)
3. Copy `Config.example.json` to `Config.json` and fill in your Discord token, API key, endpoint, and channel/role IDs. Enable Developer Mode in Discord to copy IDs — see https://support.discord.com/hc/en-us/articles/206346498-Where-can-I-find-my-User-Server-Message-ID- for how to find them. `Config.json` is gitignored so your secrets stay out of the repo. <img width="1004" alt="config file example" src="https://github.com/Raw-Darkness/IsaBot/assets/154023932/5f7f4f2a-cf66-429a-80e0-6581a8b90071">
4. Run it: `python3 IsabellBot.py` <img width="305" alt="bot running in console" src="https://github.com/Raw-Darkness/IsaBot/assets/154023932/20a92be5-1f46-4553-8bb7-4b78b34a4e19">

For image generation, run [Automatic1111 WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui) with `--api` and point `SDURL` at it. If the SD endpoint is unreachable the bot degrades gracefully and just tells the user it couldn't render.

To run it as a service on Linux (or WSL2 with systemd enabled), something like:

    [Unit]
    Description=IsaBot
    After=network.target

    [Service]
    User=youruser
    WorkingDirectory=/path/to/IsaBot
    ExecStart=/usr/bin/python3 /path/to/IsaBot/IsabellBot.py
    Restart=always
    RestartSec=5

    [Install]
    WantedBy=multi-user.target

### Config reference

    "DiscordToken":          your bot token
    "OpenAPIKey":            API key for your LLM provider (OpenAI, OpenRouter, or local)
    "OpenAPIEndpoint":       base URL of the OpenAI-compatible API
    "OpenaiModel":           model name at that endpoint

    "Name":                  the bot's name (also used for name-mention detection)
    "Personality":           system-prompt personality. Keep it tight — it is sent with every message
    "LorePath":              optional plain-text file with world/lore knowledge added to the system prompt

    "AllowedChannels":       channel IDs the bot chats in (DMs always work)
    "IgnoredUsers":          user IDs to ignore (e.g. other bots)
    "IgnoredWords":          messages containing these words are ignored
    "OnlyWhenCalled":        if true, only reply in channels when mentioned or named

    "SDURL":                 Automatic1111 txt2img API endpoint
    "SDPositivePrompt":      tags prepended to every image prompt
    "SDNegativePrompt":      negative prompt for every generation
    "SDSteps" / "SDHeight" / "SDWidth" / "cfg_scale" / "SDSampler" / "scheduler": generation settings
    "ImagePromptMaxChars":   max length of the LLM-composed SD prompt

    "SummaryOwnerID":        your Discord user ID — enables owner commands and receives daily digests (0 = disabled)
    "DailySummaryEnabled":   send a daily server digest to the owner
    "SummaryHour" / "SummaryTimezone" / "SummaryMaxPerChannel": digest scheduling

    "ModChannelID":          channel where mod alerts are posted and mod commands work (0 = disabled)
    "ModRoleID":             role allowed to use mod commands (0 = disabled)
    "HoneypotChannelID":     posting here gets non-exempt users removed (0 = disabled)
    "HoneypotExemptRoleIDs": roles exempt from the honeypot
    "HoneypotAction":        "kick" (softban: ban to wipe messages, then instantly unban) or "ban" (permanent)
    "HoneypotDeleteSeconds": how far back Discord wipes the offender's messages (default 600 = 10 min, max 604800)

    "ChannelHistoryPath":    where channel conversation memory is stored
    "DMHistoryDir":          directory for per-user DM memory
